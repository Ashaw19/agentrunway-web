Install
  1. Click Copy signature above.
  2. Gmail: Settings (gear) → See all settings → General → Signature → Create new → paste → Save changes.
  3. Apple Mail (Mac): Settings → Signatures → + → paste. Uncheck "Always match my default message font."
  4. Outlook: Settings → Mail → Compose and reply → paste into the signature box → Save.
  5. iPhone Mail app: signatures are plain-text only; use the Gmail or Outlook app instead, or accept a text-only version on iPhone.

Images load from agentrunway.ca, so the signature displays for any recipient with images enabled. Phone and email are clickable links.
